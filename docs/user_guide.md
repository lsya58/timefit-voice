# TimeFit Voice 使い方ガイド

時刻付き字幕（SRT / VTT）、または目標秒数を書いたCSVから、VOICEVOXの音声を指定された時間枠に収めるツールです。
「ぴったり」は動画全体の長さではなく、**字幕またはCSVの1行ごとの時間枠**に対する一致を意味します。

Windows配布版はZIPを展開し、無料版なら `TimeFitVoice_Free.exe`、製品版なら `TimeFitVoice_Pro.exe` を起動します。Pythonは不要です。ZIP内の `_internal` フォルダは削除・移動しないでください。Windows 10/11 と Microsoft Edge WebView2 Runtime が必要です。VOICEVOX本体は別途インストール・起動します。
設定は `%APPDATA%\TimeFitVoice\config.json` に保存され、配布版の初回起動時に作成されます。Windows版のAPIキーは現在のWindowsユーザー用に保護して保存し、旧版の平文設定は読み込み時に移行します。設定ファイルを別PCへコピーしてもキーは復号できないため、新しいPCで入力し直してください。既定の音声出力先は `%LOCALAPPDATA%\TimeFitVoice\outputs\＜入力元ごとの識別子＞\＜入力ファイル名＞_output` です。ZIPの展開先へは出力しません。

---

## 1. 準備（最初の1回だけ）

### 1-1. VOICEVOX をインストールして起動する
- 公式サイト（https://voicevox.hiroshiba.jp/）からダウンロードしてインストールします。
- **TimeFit Voice を使うときは、VOICEVOX を起動したままにしておいてください。**

### 1-2. （おすすめ）Gemini の APIキーを用意する
話速を上げても収まらない長い原稿を、AI が意味を保ったまま短くするために使います。
キーがなくても使えますが、その場合は「話速の調整だけ」で合わせます。

1. Google AI Studio（https://aistudio.google.com/）に Google アカウントでログインします。
2. 「Get API key」→「APIキーを作成」を押し、表示されたキーをコピーします。
3. TimeFit Voice の右上の歯車（設定）を開き、「APIキー」に貼り付けて「保存」します。

> 無料枠では、送った原稿が Google のサービス改善に使われる場合があります。
> 公開前の台本を送りたくない場合は、Google AI Studio で課金を有効にするか、要約をオフにしてください。

### 1-3. 動作チェック
右上の表示が「VOICEVOX 接続中」（緑）になっていれば音声エンジンは準備完了です。
設定画面の「動作チェック」を押して、すべて ✓ になれば APIキーも使えます。

## 2. 使い方

1. **台本を選ぶ**: 画面にファイルをドラッグ＆ドロップするか、「ファイルを選ぶ」から CSV / SRT / VTT を選びます。各行が時間軸に並んで表示されます。
   まず試したいときは「サンプル字幕で試す」を押してください。
2. **話者を選ぶ**: 一覧から使うキャラクターを選びます（CSV で話者IDを書いた行はそちらが優先されます）。
3. **合わせ方を選ぶ**
   - **ぴったり**: 1行の音声がその行の目標より短い場合、末尾に無音を足し、音声ファイル全体を目標秒数と同じ長さにします。話す速さを遅くして枠全体を埋める機能ではありません。
   - **以内**: 目標より短い行別WAVには無音を足さず、発話が終わった長さのままにします。ただし`combined.wav`では、SRTの開始時刻またはCSVの各行枠を守って次の音声を配置するため、次の発話まで無音になることがあります。
4. **尺合わせを開始** を押します。各行のバーに「話している部分 / 目標の枠」が表示され、▶ で1行ずつ試聴できます。
   終わったら「まとめて再生」で全体を確認し、「出力フォルダ」で結果のファイルを開きます。

### 合わせ方の順番
1. そのままの速さで収まるか
2. 句読点の「間」を少し詰めて収まるか
3. 話す速さを上げて収まるか（上限は設定の「話速の上限」、初期値 1.3倍）
4. AI で原稿を短くして、1〜3 をやり直す

それでも収まらない行は **⚠ 収まらず**（赤、はみ出した部分は斜線）で表示されます。その行は原稿を短くするか、目標秒数を延ばしてください。

### AI が書き換えた行を確認する
AI が要約した行には「✎ AI が書き換えました · 確認する」と表示されます。押すと確認画面が開きます。
- **元の原稿**: 選んでいる文で削られる部分が赤く表示されます。数字や固有名詞らしき語が消えている場合は、黄色で警告します。
- **候補**: AI が出した案です。それぞれに「推定○秒・そのまま収まる／話速×1.1で収まる」などが表示されます。クリックで選べます。
- **AI に別の案を出してもらう**: 気に入る案がないときに押すと、違う言い回しの案が追加されます。
- **この文で作る**: 自由に書き直せます。入力中も、収まるかどうかがすぐ表示されます。
- 「この文で作り直す」を押すと、その行の音声だけを作り直し、まとめ音声・字幕・結果一覧も自動で更新します（AI には送りません）。
- 「⚠ 収まらず」の行も、同じ画面（「✎ 原稿を短くする」）で直せます。

### 「ぴったり」の中身
各行のバーの下に「発話 2.56s ＋ 無音 1.44s ＝ 4.00s」のように表示されます。
「ぴったり」モードは、話し終わった後の残り時間を無音で埋めて、合計を目標の長さにそろえます（枠いっぱいにゆっくり話すわけではありません）。
字幕1つ分の区間に音声全体を収めるツールなので、単語ごとの発声タイミングを字幕に合わせるものではありません。

追加した無音が2秒以上、かつ字幕枠の半分以上を占める行には「長い無音」の品質警告が出ます。
これは処理失敗ではなく、短い原稿に対して字幕枠が長すぎる可能性を知らせるものです。映像上で意図した間か確認し、意図していなければ原稿を増やすか元の字幕時刻を見直してください。字幕の時刻はアプリが勝手に変更しません。

## 3. 台本ファイルの書き方

### 字幕ファイル（SRT / VTT）
動画編集ソフト（Premiere Pro、DaVinci Resolve、CapCut、Vrew など）で書き出した字幕をそのまま使えます。
字幕ごとに、**終了時刻－開始時刻**がその行の目標秒数になります。音声は元の字幕開始時刻に配置され、字幕と字幕の間にある空白も`combined.wav`に残ります。TimeFit Voiceが字幕の開始・終了時刻を勝手に詰めることはありません。

### CSV（Excel で作れます）
1行目に見出しを付けて、「話者ID」「秒数」「原稿」の3列にします。

| 話者ID | 秒数 | 原稿 |
|---|---|---|
| 3 | 4 | こんにちは、ずんだもんなのだ。 |
| 2 | 10 | 江戸時代、徳川家康は江戸幕府を開き…… |

- 話者IDを空欄にすると、画面で選んだ話者になります。
- 「秒数」がその行の目標時間です。CSVには絶対的な開始時刻がないため、`combined.wav`では各行をこの時間枠の順に並べます。
- `#` で始まる行は無視されます（メモに使えます）。
- 付属の `samples` フォルダに見本があります。

現在のGUIには、原稿を直接入力して秒数を指定する機能はありません。単発の原稿はCSVに1行だけ記入して使用してください。TXTをそのまま読み込み、自動で目標秒数を決める機能も現在はありません。

## 4. 出力されるファイル

| ファイル | 内容 |
|---|---|
| `001_こんにちは….wav` など | 1行ごとの音声 |
| `combined.wav` | 全部を1本にまとめた音声。字幕入力なら字幕の時刻どおり、CSV なら順番に並んでいます。**動画の先頭に置くだけで完成** |
| `fitted.srt` | AI で短くした後の原稿で作り直した字幕（音声と字幕の内容を一致させるため） |
| `report.csv` | 行ごとの結果一覧（話速、要約、実発話秒数、追加した末尾無音、次の字幕までの空白、品質警告など） |
| `credits.txt` | 動画に載せるクレジット表記（例: `VOICEVOX:ずんだもん`） |

## 5. 困ったときは

| 表示 | 対処 |
|---|---|
| 音声エンジンに接続できません | VOICEVOX を起動してから実行してください |
| APIキーが正しくないか、使えない状態です | 設定（右上の歯車）でキーを貼り直してください |
| 「1日の利用上限。回復まで約○時間」とログに出る | 無料枠ではモデルごとに1日の回数上限があります。アプリは自動で予備のモデルに切り替えるので、そのまま使えます |
| 混雑しているか利用上限に達していて… | Gemini 側の混雑か無料枠の上限です。自動で再試行・予備モデルへの切り替えをしても駄目だった場合に出ます。数分〜1日待つか、課金を有効にしてください |
| 画面が真っ白で何も表示されない | Microsoft Edge WebView2 ランタイムをインストールしてください（Windows 10/11 には通常入っています） |
| SmartScreenやウイルス対策ソフトに止められる | 起動を急がず、購入元・ファイル名・提供されたSHA-256値を確認してください。不一致なら実行せず販売者へ連絡してください。未署名のため警告が出る場合がありますが、警告の一律回避は勧めません |
| 秒数が文字化けした CSV | Excel で「CSV UTF-8」形式で保存し直してください（Shift_JIS にも対応しています） |

処理が遅いと感じたら、行のバーにマウスを乗せると「処理時間（うち AI・合成）」が見られます。ログの最後にも全体の内訳が出ます。

それでも解決しない場合は、画面下部の「ログ」の「コピー」を押して、販売ページのメッセージ機能に貼り付けてお問い合わせください。

### ほかの音声エンジン
AivisSpeech など VOICEVOX と同じ仕組みの音声エンジンは、設定の「音声エンジン」で「AivisSpeech」ボタンを押す（または URL を書き換える）と使える場合があります。
