## 1. 商品ページ下書き（製品版）

**商品名**: TimeFit Voice ― 字幕・台本を「指定秒数ぴったり」の VOICEVOX 音声にするツール

**価格**: 2,980円（発売記念 1,980円 / 最初の2週間）

**キャッチ**:
> 「この10秒に、このセリフを収めたい」
> 書き出し → 長さ確認 → 台本を削る → また書き出し……の往復を、ボタン1つで終わらせます。

**できること**
- 字幕ファイル（SRT / VTT）を読み込むだけで、**字幕の表示時間ぴったりの音声**を全部まとめて作成
- 長すぎる原稿は、①間を詰める → ②話速を上げる（上限を自分で決められる）→ ③AI が意味を保って要約、の順で自然に収めます
- タイミングどおりに並べた **1本の音声ファイル** を出力。動画の先頭に置くだけで完成
- 要約後の原稿で **字幕も作り直し**。音声と字幕がズレません
- クレジット表記（`VOICEVOX:ずんだもん` など）を自動で書き出し
- CSV（Excel）で台本を管理している方にも対応。キャラクターを行ごとに変えられます

**こんな方に**
- ショート動画（TikTok / YouTube Shorts / Reels）を VOICEVOX で作っている
- ゲーム実況・解説で、映像に合わせてナレーションを付けている
- スライド動画・PV・広告動画で、尺が先に決まっている
- 字幕を作ってから音声を付けている

**動作環境**
- Windows 10 / 11（64bit）
- VOICEVOX（無料、別途インストール）
- AI 要約を使う場合: Gemini の APIキー（Google AI Studio で発行。無料枠あり）

**無料版について**: 1回10行まで、すべての機能をお試しいただけます。まず無料版で動作をご確認ください。

**ご注意**
- 本ツールは VOICEVOX の公式ツールではありません。
- 作成した音声の利用は、VOICEVOX および各キャラクターの利用規約に従ってください。
- ダウンロード商品のため、購入後の返金はお受けできません（無料版で事前にご確認ください）。

**同梱物**: TimeFitVoice.exe / 使い方ガイド / サンプル台本 / ライセンス表記

## 3. 集客プラン

### 発売前（2〜3週間）
1. **デモ動画を作る**: このツール自体で作ったショート動画。「字幕を入れて → 実行 → タイムラインに置くだけ」を 30 秒で見せる。
2. X（Twitter）で開発の様子を投稿し、「無料版を試したい人」を募集。VOICEVOX 関連のハッシュタグを付ける。
3. 試してくれた人に感想をもらい、商品ページに載せる（掲載の許可をもらう）。

### 発売時
- 発売記念価格（2週間）で初速を作る。
- note / Zenn に「VOICEVOX の音声を字幕の長さに自動で合わせる方法」の記事を書き、無料版へ誘導する。

### 発売後
- report.csv の「収まらず」が多いケース、問い合わせ内容をもとに改善 → アップデートのたびに告知。
- 売れ行きを見て、Pro 版の追加機能（YMM4 / AviUtl 連携、翻訳吹き替え）を検討する。

### 見るべき数字
- 無料版のダウンロード数 → 製品版の購入数（切り替え率）
- デモ動画の再生数・いいね数
- 問い合わせの件数と内容（多い質問はガイドに追記）
